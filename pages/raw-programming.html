Raw Programming

Start with the stuff every language has in common.

Before Python, JavaScript, Java, C#, C++, or Lua, there are ideas that show up everywhere: instructions, rules, values, choices, and repeats.

Why start here?

A language is how you talk to the computer. Raw programming is what you are trying to say.

Where this goes

Once the basics feel less blurry, the lessons can branch into games, websites, apps, tools, modding, or whatever sounds worth building.
